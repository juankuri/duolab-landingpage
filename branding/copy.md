# Copy

## Public Website

The current approved public website copy lives in `frontend/src/content/landing.js`.

This file preserves durable copy direction and messaging rules. It should not become a second source of truth for implemented page content.

## Messaging Principles

- Resolve doubts in the patient's words.
- Prefer calm reassurance over urgency.
- Keep WhatsApp as the main public website action.
- Use plain Spanish.
- Do not use placeholder testimonials.
- Do not use "Contáctenos".

## Durable Messages

- Sin cita para la mayoría de estudios.
- Sin sorpresas de precio.
- Te decimos cómo prepararte antes de llegar.
- La mayoría de resultados están disponibles el mismo día.
- Si tu hijo le tiene miedo a las agujas, aquí sabemos cómo tratarlo.

## Landing Sections

Hero
: Explain what DuoLab is, where it operates, and why the patient can trust the result.

Trust
: Use concrete facts: years of experience, study breadth, same-day results, and no appointment for most studies.

Services
: Describe common and special studies without turning the page into a technical catalog.

Children
: Give special weight to the fear of needles and the need for patient treatment.

How It Works
: Explain arrival, sample taking, preparation, and delivery simply.

Location
: Make address, hours, and map access easy to scan.

FAQ
: Answer appointment, fasting, delivery time, price, and children-related questions.

Final CTA
: Repeat the WhatsApp action with calm urgency.
